# Binance Sentinel 24/7 Multi-Pair Cloud Bot

An institutional-grade, multi-pair cryptocurrency scanner and trading sentinel designed to operate 24/7 in the cloud.

## Features
- **10 Liquid Parities Monitored**: BTC, ETH, SOL, DOGE, XRP, SUI, AVAX, BNB, LINK, NEAR.
- **Micro-Account Sizing**: Strict $0.35 max loss risk per trade, protecting small accounts ($12-$50).
- **Hard Stop-Loss**: Immediate native `STOP_MARKET` exchange-side stop loss.
- **Paper Trading Engine**: Demo simulation active by default; zero financial risk until verified.
- **Telegram Live Feed**: Instant mobile notifications on entries, exits, and PnL.
- **Built-in Cloud Healthcheck**: Responds 200 OK to keep Render.com free tier awake.
